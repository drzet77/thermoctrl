# Программа управления температурой

Программа предназначена для управления температурой двухпозиционным регулятором. Выполняется на трекерах спутникового мониторинга [Galileosky](https://galileosky.ru/), оснащенных технологией EasyLogic. В рамках этой технологии настоящая программа классифицируется как "алгоритм" (далее по тексту).

## Подключение оборудования

1. Подключить датчик температуры DS1820 (или аналог) к шине 1-Wire трекера.
2. Подключить дискретный выход 0 трекера к катушке реле управления нагревателем с нормально замкнытыми контактами (т.е. чтобы при закрытом выходе трекера контакты реле были замкнуты, а при открытом выходе - размыкались).

## Настройка трекера

1. В Конфигураторе трекера перейти в раздел **Настройка** на вкладку **Система** и активировать  модули "Выходы" и "1-Wire", после чего применить настройки и перезагрузить трекер.
2. В разделе **Устройство** найти показания датчика и запомнить его адрес, понадобится при [настройке](#установка-новых-значений) алгоритма.
3. Загрузить в память трекера настоящий алгоритм EasyLogic.

## Работа программы

После запуска выполняется инициализационное ожидание в течение ~10 с, затем циклически:

- считывается текущее значение температуры с датчика,
- текущая температура сравнивается с заданной и по двухпозиционному закону с гистерезисом выполняется управление нагревателем: при текущей температуре ниже либо равной разности заданной температуры и гистеразиса управляющий выход *закрывается* для нагрева, а при текущей температуре выше заданной выход *открывается* для охлаждения.

На протяжении всего времени работы алгоритма осуществляется обработка [команд](#команды).

## Команды

### Просмотр текущих значений

Формат команды:

`THERMOCTRLSET`

(без параметров)

Ответ:

"t=%d,s=%d,h=%d,i=%d"

где

t - текущая температура, градусы С  
s - уставка температуры, градусы С  
h - гистерезис, градусы С  
i - адрес датчика в десятичном виде

### Установка новых значений

Формат команды:

`THERMOCTRLSET s<,h<,i>>`

где

s - уставка температуры, градусы С, по умолчанию **18**  
h - гистерезис, градусы С (необязательный параметр), минимум 1, по умолчанию **1**  
i - адрес датчика в десятичном виде (необязательный параметр), по умолчанию **124**

Ответ:

см. ответ на команду просмотра текущий значений

Новые параметры вступают в действие сразу, но действуют только до перезагрузки трекера. При необходимости сохранения новых параметров в долговременной памяти необходимо создать и загрузить дополнительный настроечный алгоритм, который при своем запуске подает команду с необходимыми настройками.

Примеры:

1. Установка новой температуры:  
`THERMOCTRLSET 22`  - для задания температуры 22 градуса
2. Установка нового гистерезиса:  
`THERMOCTRLSET 22,2`  - для задания температуры 22 градуса и гистерезиса 2 радуса
3. Установка нового адреса датчика:  
`THERMOCTRLSET 22,2,117`  - для задания температуры 22 градуса, гистерезиса 2 радуса и адреса датчика 117
